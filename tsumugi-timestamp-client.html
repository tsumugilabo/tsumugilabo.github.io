TSUMUGI タイムスタンプクライアント

PDFなどのファイルにRFC 3161タイムスタンプを付け、付けたタイムスタンプを検証するWindows用アプリです（アプリ名: TSUMUGI Timestamp Client）。

0.7版 Windows 10/11 RFC 3161 PAdES

FEATURES

できること

PDFとそれ以外のファイルに押印

PDFは、PDFの中にタイムスタンプを埋め込みます（PAdES）。PDF以外のファイルは、同じフォルダに「元の名前.tst」と「元の名前.tst.meta」を作ります。

検証は誰でも無料

付けたタイムスタンプの検証は、登録キー無しで誰でも無料でできます。

押印先を選べる

  • TSUMUGI タイムスタンプサービス（登録キーが必要）
  • 利用者が契約した外部のTSA（登録キー不要。当方サーバへは通信しません）

添付と変換

PDFにファイルを添付できます。Word・ExcelはLibreOffice（別途インストール）でPDFに変換してから押印できます。

REQUIREMENTS

動作環境

  • Windows 10/11（64ビット）
  • .NET 10 デスクトップ ランタイム
  • インターネット接続
